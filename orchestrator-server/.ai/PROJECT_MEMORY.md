# Project Memory Store (`.ai` folder)

## Why This Folder Exists

The `.ai` folder is the **persistent memory** for this project. It's created automatically when you run:

```bash
orchestrator project register --id <id> --name <name> --root <path>
```

Think of it as the orchestrator's **"brain" for this project** — it remembers everything across CLI restarts.

---

## What Gets Stored Here

### 1. **Conventions** (`.ai/conventions/`)
Extracted patterns from your codebase:
- Naming conventions (packages, classes, methods)
- Architecture patterns (layered, hexagonal, etc.)
- Testing patterns (unit, integration, testcontainers)
- Code style preferences (indentation, imports, annotations)

### 2. **Learnings** (`.ai/learnings/`)
Patterns discovered during generation/repair:
- Successful implementation approaches
- Common failure modes and fixes
- Security violations caught and corrected
- Performance optimizations applied

### 3. **Context Index** (`.ai/context/`)
Smart file relevance for AI context:
- TF-IDF scored file importance
- Dependency graph snapshots
- Recently modified files
- Test coverage mappings

### 4. **Repair History** (`.ai/repairs/`)
Artifacts from automated repair loops:
- Failed verification outputs
- Applied fixes (before/after)
- Root cause analyses
- Regression test fixtures

## Why It Matters

| Without `.ai` | With `.ai` |
|---------------|------------|
| AI starts fresh every run | AI remembers your project |
| Repeats same mistakes | Learns from past failures |
| Generic code generation | Project-specific conventions |
| No context awareness | Smart file selection |

---

## Persistence

| Profile | Storage | Survives Restart |
|---------|---------|------------------|
| `default` (H2) | In-memory | ❌ No |
| `prod` (SQLite) | File-based (`orchestrator.db`) | ✅ Yes |

**Use `--spring.profiles.active=prod` for persistent memory.**

---

## Safety

- **Read-only for users** — Don't edit files manually
- **Auto-managed** — Orchestrator creates/updates automatically
- **Git-friendly** — Add `.ai/` to `.gitignore` (contains local state)
- **Project-scoped** — One `.ai` per registered project root

## Commands That Use It

```bash
# Creates .ai folder
orchestrator project register --id myproj --name "My Project" --root .

# Uses .ai for context-aware generation
orchestrator generate "Add REST endpoint" --project myproj

# Stores learnings after successful task
# (automatic after COMPLETED status)
```
